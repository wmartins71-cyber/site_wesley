# Portfólio — Wesley Martins da Costa

Portfólio profissional direcionado a oportunidades de **Design Ops, Tools & AI**, com ênfase em sistemas, automação, Design Systems e colaboração entre Design e Engenharia.

## Stack

Site estático em HTML, CSS e JavaScript, sem dependências ou dados em tempo de execução. Pode ser publicado diretamente na Vercel.

## Estrutura

- `index.html`: conteúdo, SEO e estrutura semântica.
- `styles.css`: Design System visual, responsividade e acessibilidade.
- `script.js`: navegação suave com respeito à preferência de redução de movimento.
- `Insumos/` e `MCP Server Figma/`: fontes originais, não são carregadas pelo site.

## Executar localmente

Abra `index.html` em um navegador ou use qualquer servidor estático. Como não há dependências, não há etapa de instalação ou build.

## Publicar na Vercel

1. Envie esta pasta para um repositório Git.
2. Importe o repositório na Vercel.
3. Selecione o preset **Other**; não há comando de build nem diretório de saída.
4. Publique.

Para um domínio `.com.br` no Registro.br: adicione o domínio no projeto Vercel, copie os registros DNS solicitados e configure-os na zona DNS do Registro.br. Aguarde a propagação e confirme o domínio na Vercel.

Credenciais, tokens, estimativas de custo e detalhes internos encontrados nos materiais não são usados no site. O `.gitignore` bloqueia arquivos de ambiente e artefatos locais.

## Decisões de Design

Direção editorial clara, com grid, tipografia forte e diagramas nativos em CSS. A paleta verde sugere sistemas e eficiência sem reproduzir a identidade de uma empresa. As métricas aparecem apenas onde há evidência; a narrativa privilegia problema → intervenção → evidência → resultado.
